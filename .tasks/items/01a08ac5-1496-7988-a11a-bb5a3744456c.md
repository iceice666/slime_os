# MAVLink heartbeat over an RFD900x on the H1V1

## Context

The H1V1 boots seL4, `slime-root`, and a resident Slisp shell over UART0 (P6.A-P6.C), and its
PWM bench probe has driven an actuator from the vendor prompt (P6.PWM). Nothing in the tree
transmits anything outward: the only serial path is UART0, which is the kernel's debug console
and the shell's input.

This lane makes Slime OS emit one MAVLink v2 HEARTBEAT per second through the SoC's UART7 into
an RFD900x telemetry radio, so a ground station sees the board as a live MAVLink system.
Transmit only. Receiving commands needs an interrupt source, a bounded input path separate from
the console, and a parser for untrusted frames, none of which this lane builds.

It is cut into a board-specific bench probe, a board-neutral mechanism, and a board-specific
gate, on the P6.PWM pattern and for the same reason: the general half carries no NT98690 detail.

## Exit conditions

Every child closes on its own observed evidence. This item closes when a ground station's radio
decodes consecutive MAVLink heartbeats transmitted by a resident Slime graph on the named board.
