# Framework removable-media CPU boot

## Context

The physical claim. The Framework 13 has no serial port, so the readiness
record had to reach the panel: this milestone taught the seL4 fork's Multiboot2
header to request a linear framebuffer at all, and `slime-root` to validate and
render into the mode the firmware programmed.

Four defects were found only on hardware, all in this milestone's own code and
all invisible to the emulated planes: a CSlot/provenance leak per framebuffer
granule, a fatal path with no channel on a serial-less machine, a device untyped
whose free index resets when its last capability is deleted, and glyph rendering
that left the bootloader's console text showing through.

## Exit condition (observed)

Observed 2026-09-13 on the named Framework 13 (AMD Ryzen AI 300 Series, INSYDE
Corp. firmware 03.04, Secure Boot disabled). Two cold boots of image
`95a0d213c1249cc7...` from the removable device, each reaching the resident
product graph's declared terminal state at the panel's native `2256x1504x32`
with generation `0F1929F39BF5FA1F` legible, no keyboard input, and the first
16 MiB of `/dev/nvme0n1` hashing `a20de77e945f02d3...` both before and after.

`just framework_cpu_boot_check` refuses nineteen re-stamped forgeries before
reporting the claim. This closes only the CPU/product boot path and unblocks H1;
it completes no hardware inventory and qualifies no device.

## Evidence

[2026-09-13-p6-6-framework-cpu-boot](../devlog/2026-09-13-p6-6-framework-cpu-boot/index.md),
record at `evidence/framework-cpu-boot/slime-cpu-boot.observation.json`.

The physical boot was observed and is not retracted, but re-establishing the
repository as a clean source baseline changed `slime-root.elf`, so the recorded
observation no longer binds to a buildable medium and
`just framework_cpu_boot_check` fails on the identity comparison. The pc99
kernel is byte-identical to its pin; only the root differs. Re-closing the gate
needs a new operator boot of the rebuilt image. See the `## Corrections` section
of [the P6.6 devlog entry](../devlog/2026-09-13-p6-6-framework-cpu-boot/index.md).
