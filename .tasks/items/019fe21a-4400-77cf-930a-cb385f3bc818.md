# three scenario receive spins were invisible to the root

## Context

Resolved 2026-08-09.

the call plane's terminal receiver and two operation-plane receive paths used `yield_now()` on `ERR_WOULDBLOCK`, so the root could neither name their endpoint wait nor distinguish a real dependency from an iteration-budget spin.
