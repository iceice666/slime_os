# Network data plane over LinkDevice: TCP for the IO substrate

## Context

IO3 moves raw Ethernet frames through a supervised userspace virtio-net driver behind
`LinkDevice`, and IO4 decides, from generation data, which exact destinations a component
may reach. Nothing connects them: no ARP, IPv4, ICMP, UDP, TCP, or DNS exists, and IO4's
service is bound to a loopback that performs no link operation. This lane fills that gap
with a bounded TCP data plane inside `network-service`, consuming `LinkDevice` below and
serving the existing `network-service/v1` protocol above under QEMU.

The QEMU milestone names no SoC and makes no physical-device qualification claim.

## Exit conditions

Every child closes on its own observed evidence. This item closes when a TCP byte stream
to one generation-declared destination is observed under QEMU.
