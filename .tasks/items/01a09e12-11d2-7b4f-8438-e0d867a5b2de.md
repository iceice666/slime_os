# GRUB Multiboot2 boot contract

## Context

One GRUB Multiboot2 EFI layout shared by QEMU and removable media. pc99 is the
only platform on this route: the pinned rust-sel4 loader implements Arm and
RISC-V assembly only, and seL4 pc99 already consumes Multiboot modules, so the
kernel and root task stay separate modules rather than a loader-wrapped ELF.

## Exit condition (observed)

Pinned QEMU q35/OVMF boots seL4 and `slime-root` through that layout, with the
firmware, bootloader, module set, and tree digest all pinned.
