# contracts_check dominates system_spec_check once the spec passes are cached

## Context

Measured 2026-09-11 after the zutai cache (`01a090af-08a4-763b-8a9f-76b7d6376dd4`): the two
scripts `just system_spec_check` adds take 3.1 s and 1.7 s warm, but the recipe still takes
190 s because it depends on `component_spec_check`, which depends on `contracts_check`:
four `zutai-cli model-check` runs, `check-contracts.py`, `check-generation-v5.py`, and nine
binding `--check` generators, none of which the cache touches.

## Scope

Find where those 190 s go and whether the same content-keyed memoization or a narrower
dependency edge removes them without weakening what the recipe proves.

## Exit conditions

`just system_spec_check` with a warm cache and no spec changed completes in under two
minutes on a 16-core host, with the same set of checks still executed.

## Verification

Gates: `just system_spec_check`, `just contracts_check`

## Observed 2026-10-04: the bottleneck moved

Against `origin/main` at `3d6eb030`, on an 18-core macOS host:

- #73 (`281c7f80`) already narrowed the edge: `system_spec_check` now depends
  on `component_spec_validation_check`, not on `contracts_check`, which stays
  its own gate.
- The exit condition still does not hold. A second, warm
  `nix develop -c just system_spec_check` took 138 s (exit 0). Run separately:
  `check-component-spec.py` 1 s, `check-system-spec.py` 134 s,
  `generate-generation-from-spec.py --check` 18 s.
- Under `cProfile`, `check-system-spec.py` spent about 125 s of 128 s in 226
  subprocess calls. Most of that is 54 `render_computed_system` runs of the
  `system-spec-source` adapter, about 2.3 s each with no memoization, and
  `computed_source_controls` alone took 107 s: each
  `check_computed_systems` call renders all six `COMPUTED_SYSTEM_SOURCES`
  serially. One adapter run peaked at about 4.3 GB resident.

Candidate directions, not chosen: render the six sources concurrently with a
memory-bounded width, or add a content-keyed render cache whose key covers the
full import closure, which the mutation controls deliberately perturb.
