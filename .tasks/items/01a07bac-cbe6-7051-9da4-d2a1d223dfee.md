# Servo PWM on the H1V1

## Context

Closes the lane on the named board: the root carves and maps the PWM page, programs the channel
clock and the pad routing once from pinned values, and hands the page to the userspace driver,
which the resident Slisp shell commands.

The PWM page must be carved after the watchdog granule and before the UART granule -- device
untypeds retype monotonically upward, and P6.C already observed what happens when that order is
wrong.

## Exit conditions

On the named Novatek NT98690 H1V1, from one power-on: the resident shell answers
`(pwm 0 1000)`, `(pwm 0 1600)`, `(pwm 0 1200)`, and `(pwm 0 0)`; after each the driver reads
back the enable bit and the period registers the pinned encoding predicts; the gate-only
terminator returns the board to its vendor firmware; zero framing errors. An ESC arming and
running fast then slow is recorded as an operator observation, not as a marker.

## Verification

Gates: `just nt98690_pwm_check <serial>`, `just nt98690_slisp_check <serial>`,
`just sel4_gate_control_check`
