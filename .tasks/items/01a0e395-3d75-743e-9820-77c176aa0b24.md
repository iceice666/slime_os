# framework_cpu_boot_verify recipe named in product.just does not exist

## Context

`just/product.just` documents the P6.6 recipes as `framework_cpu_boot_check`, `framework_cpu_boot_prepare`, and `framework_cpu_boot_verify`, but only the first two are defined. `scripts/check/check-framework-cpu-boot.py verify` exists and takes nine required operator arguments; the runbook in docs/operations/framework-cpu-boot-runbook.md currently tells operators to call the script directly.

AGENTS.md's command list also describes `check-framework-cpu-boot.py verify` without a recipe.

## Exit condition

Either a `framework_cpu_boot_verify` recipe exists (with a documented argument shape, depending on `framework_media_check` like its siblings) and the runbook uses it, or the recipe comment and AGENTS.md stop naming one. `just docs_check` passes either way.

## Closure evidence

Took the first option, on branch `fix/backlog-bootstate-verify` from `origin/main` at `35ca61d`. `just/product.just` now defines `framework_cpu_boot_verify *ARGS: framework_media_check` with `[positional-arguments]`, passing its arguments unchanged to `scripts/check/check-framework-cpu-boot.py verify`; the comment above it states the argument shape. The runbook's section 5 (`docs/operations/framework-cpu-boot-runbook.md`) calls `sudo -E just framework_cpu_boot_verify ...` and no longer says the alias is missing. AGENTS.md names the recipe, and `docs/reference/just-targets.md` lists it.

Observed on 2026-09-28 (macOS host, not a Framework):

- `just --list` lists `framework_cpu_boot_verify *ARGS`, and `just --dry-run` shows `framework_media_check` running before it.
- `just --no-deps framework_cpu_boot_verify --help` prints the `verify` subcommand's usage. With every required argument, including `--machine-product "Laptop 13 (AMD Ryzen AI 300 Series)"` and `--operator "a b"`, the script parsed them and refused with `missing boot media build/framework-media/slime-framework.img`, so quoted multi-word values arrive as single arguments.
- `just docs_check` passed (199 maintained documents), as did `just typos` and `just tasks_check`.

Not observed: the `framework_media_check` dependency was not run for this change, and no physical `verify` was performed; the recipe changes no checker behavior.
