# `slime-root`'s unit tests were run by no gate

## Context

Resolved 2026-08-07.

102 `#[test]` functions across 13 modules were compiled and run by nothing — no Justfile target named the crate, and it could not have run anyway since `main.rs` was unconditionally `no_std`/`no_main` with no `lib` target and no `libtest` for its seL4 JSON target.

## Exit conditions

the mechanism modules were split into a `slime_root` library the binary links, so all 13 covered modules run on a host target given `SEL4_PREFIX`; `just test_sel4_root` runs 102 tests across 13 modules and asserts the count; the first run found three latent test-bug defects (stale push call sites, a wrong ELF-header fixture length, a stale qualified-fixture tail) — all test bugs, not production bugs.

## Verification

Gates: `just test_sel4_root`
