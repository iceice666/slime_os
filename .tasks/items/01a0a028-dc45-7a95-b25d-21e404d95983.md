# Closures still pin rust-sel4 d441a880 after #61 moved deps/rust-sel4 to 14d98403, so every closure-built plane fails to resolve

## Context

PR #61 moved `deps/rust-sel4` from `d441a880` to `14d98403` without
regenerating `contracts/system-image-closure/v2`. Every closure records the
rust-sel4 commit and the `deps/rust-sel4` tree identity as build inputs, and
the resolver refuses a closure whose pin disagrees with `sel4/pins.toml`, so
every closure-built plane failed with
`closure rust-sel4 commit does not match the source pin`. CI's rollback job
was red on the PR branch and on `main` after merge.

## Exit condition (observed)

Observed 2026-09-14: `scripts/generate/generate-system-image-closures.py` run
from a clean checkout of `0361bff4` re-renders 60 closures (the
`rustSel4Commit` line and seven tree identities each) and `--check` reports
them current; `just sel4_sample_check` and `just sel4_rollback_check`, both
closure-built, pass on that tree. No prefix or test-run record moved.
