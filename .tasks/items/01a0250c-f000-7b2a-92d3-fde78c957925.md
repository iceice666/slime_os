# component definitions and slot/route bindings are compile-time-coupled to one crate's private manifest parser, blocking out-of-tree components

## Context

Resolved 2026-08-22. **Class:** Debt (a compile-time coupling that made out-of-tree component development architecturally impossible, closed over the CP0-CP5 track and eleven incremental migrations).

Nineteen component sources compiled their CSpace slot numbers, route tables, QoS policies, declared ceilings, command tables, and the composition they branch on out of `build.rs`-private constant tables one crate generated by string-parsing one generation manifest, so no component could be built outside that crate against that manifest.

Class: Debt (a compile-time coupling that made out-of-tree component development architecturally impossible, closed over the CP0-CP5 track and eleven incremental migrations).

## Exit conditions

`contracts/component-spec/v1` and `contracts/system-spec/v1` exist and validate under `just contracts_check`; `valid.zti` and `sel4-channel.zti` derive from those sources byte-identically; no component source `include!`s a manifest-derived constant table, the renderer and both command generators are deleted, and the full seL4 gate suite passes.

## Verification

Gates: `just contracts_check`
