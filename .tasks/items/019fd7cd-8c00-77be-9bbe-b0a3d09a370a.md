# the `[layout]` dump reported the grant's rights, so a too-permissive layout row was unobservable

## Context

Resolved 2026-08-07.

`main.rs`'s boot-layout dump printed each row's rights from the installed capability (filled from the generation grant) rather than from the boot-layout entry the row exists to freeze, so a layout declaring strictly more authority than anything used was invisible — the one direction of disagreement B10's containment check was blind to.

## Exit conditions

`declared_layout_rights` resolves the layout entry behind a bootstrap row and appends `declared=0x…` only when it differs from the installed value; a previously-invisible rights-widening injection now fails the gate, and re-blessing surfaced three pre-existing, now-recorded containment differences on `sel4-loan`/`sel4-sample`/`sel4-stream`.
