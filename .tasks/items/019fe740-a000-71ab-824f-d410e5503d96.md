# generation component records conflate executable catalogue entries with initial instances

## Context

Resolved 2026-08-10.

`slime-root` constructed and activated every loadable component in the generation while `init` also spawned the graph it owns, so the full C8.10 image ran a root-launched copy and an init-spawned copy of the same fabric/workers, and the format had one `Component` record for two different concepts (executable vs. required-at-boot instance) with no launch-owner or autostart field.

## Exit conditions

a generation-format cutover separates `Executable` from `Instance` records; a fixture can carry executable-only images without creating tasks; every declared initial instance is constructed exactly once by its declared owner; `just sel4_boot_check` observes the single graph's complete healthy-idle chain.

## Verification

Gates: `just sel4_boot_check`
