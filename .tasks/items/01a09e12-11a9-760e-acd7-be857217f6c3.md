# x86-64 seL4 target admission and reproducible build

## Context

Admits both x86-64 target profiles and pins every input the pc99 build reads:
kernel configuration, toolchain, QEMU machine facts, and the two repo-owned
Rust target specifications, which exist because upstream's softfloat ABI has no
LLVM lowering for `slime-root`'s 128-bit release-signature arithmetic.

## Exit condition (observed)

`just x86_64_sel4_image_check` builds twice byte-identically, refuses the wrong
architecture, ABI, page profile, machine profile, and feature set with distinct
errors, and makes no boot claim.
