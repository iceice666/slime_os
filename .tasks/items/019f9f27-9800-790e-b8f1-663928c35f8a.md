# Attenuated endpoint provisioning and control plane

## Context

Complete.

## Exit conditions

The live fabric derives exact non-widening, non-transferable route endpoints from the authenticated generation graph; on a real boot the publisher holds `RIGHT_SEND` only and the subscriber `RIGHT_RECV` only, and `fabric-intruder` — holding a real generation-provisioned control endpoint and supplying byte-identical route strings — receives a denial carrying no capability. The "consumes no CPU through a poll/yield loop" arm is proven by a source lint (the gate rejects any fabric component containing `yield_now` or lacking a `SYS_WAIT` park), a necessary condition rather than a direct measurement.
